# Per-device answer history

The protected /admin dashboard now has a per-device answer browser. Filter by subject, FY24–FY26 A/B exam, outcome, or exact stable question ID; request older records in pages of 50. Wrong, partial and unanswered records are the default. Names remain the existing device nicknames. Same-origin IndexedDB identifies one browser installation across four subjects; clearing site data, private windows or another browser creates a different identity.

The optional `answer_record` event uses an explicit primitive-field allowlist. It contains question identity, submitted answer, registered answer/example where available, outcome, grading method, explanation and original answer time. It never sends whole state, credentials or drafts. Answer text is bounded and long text is marked as shortened. Older records without saved answers are labelled missing; they are not reconstructed. English writing records represent AI feedback, and Kokugo self-grading is explicitly distinguished from objective grading. No official score or learner thought process is inferred.

The existing registration, school namespace, credential validation, outbox, retry and revocation mechanisms are retained. Answer records are accepted for unclassified devices too; ignored and revoked registrations stop collecting. Existing unclassified quotas still apply. Duplicate event IDs are idempotent; revisions expose only the current revision per record. Answer details do not inflate progress aggregates. Cloudflare Access protects all history reads; there is no learner-readable answer history endpoint.

Validation on 2026-10-18: common unit/transport regressions, Miniflare runtime registration/control/summary/revoke tests, signed-JWT admin tests, four subject answer submissions, device isolation, duplicate/revision handling, malformed/nested payload rejection, ignored/revoked controls, question/subject/outcome filters and 50-row pagination. Two consecutive browser rounds at 390px and 1280px verify English wrong choice text, math answer/expected answer, vocabulary wrong choice and reload persistence, Kokugo self-grading, a shared four-subject device identity, escaped HTML in submitted answers and no horizontal overflow in the admin. Browser fixtures intercept Cloud writes; no real learner history is overwritten.
